# Faceless / Explainer playbook

No presenter. The script drives everything.

1. **Script first** – write or refine the VO script in the storyboard; ~2.5 words/second.
   Every factual statement must come from the brief or a source the user gave.
2. **Voiceover** – user-recorded VO preferred. If none, offer local TTS (Kokoro, if installed)
   and say clearly that it's synthetic. Never clone a real person's voice.
3. **Visuals** – kinetic typography, icons, diagrams, charts (real numbers only), user images.
   One idea per scene; change something visually every 2–4 s.
4. **Captions** – always on for social formats.
5. **Music & SFX** – bed under VO, light hits on scene changes.

Structure template: Hook question/claim → Why it matters → 3 key points → Summary → CTA.
